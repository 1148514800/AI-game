岑砚在第 233.19 秒完成屋顶修缮，在第 252.38 秒独立修通旧桥。桥梁的六份木材、两份石材和 14 秒工时均记在岑砚名下。阿禾和洛舟没有桥梁材料或施工入账。

## 第二轮

岑砚在第 33.18 秒修好屋顶。洛舟向旧桥交付两份石材，岑砚交付六份木材并完成全部施工，旧桥在第 293.69 秒修通。阿禾的桥梁材料和工时均为零。

洛舟在第 441.87 秒发现航标，第 450.47 秒分享给旅人，随后又在第 456.43 秒发现星纹石碑。阿禾在第 536.69 秒交齐两份食物，第 538.43 秒收到洛舟分享的石碑线索，保存了正文及其来源。
