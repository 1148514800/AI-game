# 洛舟过桥探索与线索分享复测

三轮均使用独立的空白后续进度与真实模型配置。旧桥在测试开始时设为已修通，遗迹发现与分享记录均为空。两轮由三位居民自由选择所有行动。第三轮用已接受的同行计划复现同伴尚未动身的情况，之后由洛舟的真实模型决定如何分享。通过游戏服务的 WebSocket 推进世界，发现与分享由正常规则执行。

| 场景 | 首次发现 | 首次分享 | 持久化接收者 |
|---|---:|---:|---|
| 自由决策一轮 | 12.37 秒 | 22.20 秒 | 阿禾 |
| 自由决策二轮 | 7.36 秒 | 22.60 秒 | 阿禾 |
| 同伴未动身 | 3.24 秒 | 17.70 秒 | 阿禾 |

三轮均产生洛舟的发现回执、分享回执和阿禾以洛舟为来源的事实记忆。第二轮还发现了星纹石碑，三个场景都在首次成功分享后结束。同行场景中，洛舟独立完成已选定的目的地行程，记录中没有同行超时。

实际请求、规则动作和保存结果见[摘要](summary.json)、[第一轮](free-1/report.json)、[第二轮](free-2/report.json)和[同行场景](follow/report.json)。每轮目录另附决策及行动记录。

类型检查、87 项单元测试、7 项集成测试、生产构建和生产冒烟均通过。三轮共记录 29 次真实模型请求。
