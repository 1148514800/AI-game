# Phase 5 真实模型复测

两轮使用独立 SQLite 存档和真实模型配置。测试开始时旧桥已修通，屋顶、营地和遗迹记录为空。第一轮由三位居民自由选择行动。第二轮额外放入一项已选择的邀谈动作，用于复验发起后双方的真实回应。两轮的施工、交接、探索和分享均由游戏规则执行。

第一轮在 104.14 秒内达成三项目标。岑砚提交两份木材并独立完成 6,000 毫秒施工量，完工发生在第 100.47 秒。阿禾在第 103.22 秒提交第二份食物，营地达标。洛舟在第 7.74 秒发现航标线索，在第 29.85 秒分享给阿禾。阿禾的持久化记忆记录了线索内容及洛舟来源。真实模型账本共 19 次请求。见[运行摘要](bridge-open/report.json)、[行动回执](bridge-open/events.jsonl)、[模型决策](bridge-open/decisions.jsonl)及[收件记忆](bridge-open/clue-receipt.json)。

第二轮观察了 309.49 秒。真实模型完成四次邀谈，其中测试开场由洛舟、阿禾、洛舟交替发言并在 9.05 秒正常结束。岑砚于 116.75 秒完成屋顶，阿禾随后交足两份食物，最终营地达到四份。洛舟出现一次同行超时，之后继续走向东岸，在观测结束前未触发发现或分享回执。账本共 60 次请求。见[运行摘要](invitation/report.json)、[行动回执](invitation/events.jsonl)及[模型决策](invitation/decisions.jsonl)。

两轮账本累计记录 79 次请求，计入约 0.02836 美元。测试单独提高了请求次数和单条输出上限，沿用原服务的金额限制和价格配置。代码检查通过类型检查、86 项单元测试、7 项集成测试以及生产构建和生产冒烟。
