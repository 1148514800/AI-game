## 1. 通用化 NPC，不为阿禾洛舟复制整套岑砚代码

按角色 ID 管理独立 `ActorState`（建议 `actors: { cenyan, ahe, luozhou }`，具体结构可依现有代码调整）。每名角色至少有：位置、朝向、背包、当前目标、当前计划、pending、长期记忆、简单关系。

三名 AI 共用：人格配置读取、世界感知、记忆、模型调用、自主决策、能力定义、行动执行、社交、请求生命周期、预算。人格与数据必须独立，使用 `data/npcs/cenyan.json`、`ahe.json`、`luozhou.json`。

- 岑砚：谨慎务实、重视承诺；为漏雨屋顶储备木料；权衡公共旧桥与自身利益；保留现有状态、人格与历史记忆。
- 阿禾：热心勤劳、重视公平；储备生活物资、改善村庄生活；可主动采集、分享、提出合作；对长期不公平可不满或拒绝。
- 洛舟：好奇、愿意探索；希望修通旧桥并查看航标遗迹；更愿主动邀请他人参加公共工程；可采集、协商、前往已解锁地点；不得突破碰撞与通行规则。

地图中三人已有位置与介绍，不要新增第四名 AI，不要扩大地图。

## 2. 感知与记忆隔离

上下文至少包含：自身人格与目标；位置、背包、当前计划；附近人物与资源；公共工程；与当前对象有关的关系和承诺；最近行动结果；相关长期记忆；当前可用能力。

不得自动共享私人记忆、私包或未公开目标。公共工程等可公开。区分规则确认的事实、他人陈述、自身看法、未履行承诺。同一事件可为多名参与者写入独立记忆，但不广播。限制检索数量、上下文长度与普通写入频率。继续 SQLite，不引入向量库。重启后三人记忆与关系均正确恢复。

## 3. NPC 自主 talk

新增如 `{ "type":"talk", "target_id":"ahe", "topic":"..." }` 的能力（协议可调整）。流程：发起者选对象与话题 → 移动到交谈距离 → 自然语言 → 接收者依据自身人格、记忆与状态独立决策并回复或提出计划 → 结束。

- 不必等玩家指令；双方各做一次独立模型决策，禁止一次调用代替双方。
- 接收者可同意、拒绝、暂缓或另议。
- 不冻结世界。每名 NPC 同时最多一场交流。玩家可观察附近对白。
- 承诺与资源转移必须经规则确认。
- 初始限制：每场最多四条角色发言；同一角色对之间普通交流冷却约三分钟；超时、距离失效、暂停或断线时安全结束。不要因每条对白自动无限回复。调整限制须在 DECISIONS 记录理由。

## 4. 任意合法角色协作

将 Phase 3.1 玩家–岑砚协作推广到任意合法角色：邀请前往、采集分工、赠送或请求、分批交材、共同施工、拒绝、调整计划。Live 不得写死分工，须由模型按实际情况生成。玩家可加入已有合作；三名 NPC 也可在没有玩家资源的情况下完成旧桥。保留玩家独立通关，避免因拒绝合作而死档。每个角色始终保留独立行动权。

## 5. 遗留修复

- 有限条件等待（程序规则，禁止模型生成任意条件代码）：材料齐备、对象到达、赠送回应等。必须有超时、取消、失效；满足后继续已授权后续行动，不多调模型。
- 通用 follow：解绑旧桥硬编码；可跟随玩家或其他 NPC 去合法目的地；支持取消、超时、不可达、动态碰撞；避免互跟循环。
- 按场景提供必要能力与参数，减少重复 JSON 示例和无关历史。保留严格 Schema、JSON Mode、thinking 三态与上下文预算。不直接无限扩大 Token。

## 6. 关系、承诺、交换与借还

轻量有方向关系，优先简单信任等级（不信任 / 有所保留 / 普通 / 信任 / 高度信任）。程序按已确认事件限定变化：成功赠送、共同完工、履行已接受承诺、违背已接受承诺。正常拒绝不自动当失信。模型不能直接改关系数值。不同角色对同一对象的信任可以不同。

最小承诺：`proposed` / `accepted` / `fulfilled` / `cancelled`。稳定 ID、相关角色、可验证条件、有效期。口头意向不自动成承诺；受控结构化操作提出或接受；只有真实行动才能标履行；模型不能宣布完成；到期或取消保留记录；防重复与无限累积。

任意角色可交接木石。交换须双方明确同意并在同一事务完成。借用通过实际转移加归还承诺；归还须合法行动，不得擅自从借用者背包扣除。校验距离、物品、数量、容量、身份；原子执行；唯一回执；过期与取消；无负库存、无凭空产生。无货币、定价、利息或市场。

## 7. 调度与预算

每名 NPC 独立状态与触发：计划完成/失败、重要公共事件、交流或合作邀请、待处理承诺、约 120 秒周期。重要事件可提前，但受冷却与预算限制。

- 每 NPC 同时最多 1 个模型请求；世界初始最多 2 个并发。
- 玩家对话优先于普通自主决策。
- 不让单 NPC 耗尽全部额度。合并去重事件。有效计划执行中不重复无意义调用。
- 对话双方防死锁。
- 关闭自主 AI、暂停、断线或退出后不发后台真实调用，不补跑离线决策。
- 三人共用已有持久预算账本，不得把总预算乘以三，不擅自提高用户已配置真实额度。按角色、用途和模型记账，保留每分钟、会话、累计请求、Token 与金额限制。

请求须关联角色 ID、世界代次、计划代次及必要社交会话 ID。过期响应不得修改其他角色或覆盖新计划。

## 8. UI
