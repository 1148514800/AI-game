## 原有程序限制与本次解决

| 原限制 | Phase3.1 实际规则 |
|---|---|
| 单个角色必须一次交齐六木两石 | 玩家和岑砚可多次分批交木或石，也可交尽当前有效材料。指定超量取请求、实际库存、工程缺口的最小值，其余不扣。材料/具名贡献/工程/事实记忆/唯一回执同事务，重复成功请求返回原回执。UI和模型均看到真实缺口。 |
| 没有受控双向交接 | 木石双向赠送。玩家正式表单提议后，由模型以绑定 ID 的决定接受/拒绝；岑砚 `give_item` 只提出赠送，必须玩家点接受才能转移。90秒期限、范围、双方、库存和每类999容量在确认时重验。提议不预扣或冻结材料，拒绝/过期/失败不丢物。 |
| 只能去固定目标 | `follow` 动态读取运行时玩家坐标，服务器A*、碰撞、275ms重寻路门限、停走与恢复，不瞬移或穿未修桥。约22像素停步、8像素碰撞边界；到旧桥、玩家取消、持续不可达或60秒活动时限结束。关对话后已接受计划继续。 |
| 单角色施工互斥 | 双方各自主动参加，统一tick一次计算公共进度。单人原1倍、双人2倍；最后一步按实际剩余等分工时，一方退出另一方继续。各人工时及重叠时间真实保存，完工与共同经历只提交一次。 |
| 三个硬目标、不能换计划、暂缓丢失 | `goal` 支持1–80字自然语言，必要标签 `goal_tag` 可选，旧三个ID自动映射。`continue/reject`保留当前和pending；`replace`安全中断move/wait/work、清pending，不回滚已完成资源/工时；`defer`持久保存唯一pending，当前一步结束后同事务提升并重验，第二个pending明确拒绝。 |
| 能力、提示、Schema容易不同步 | 统一八项能力定义名称、参数、目标、前置、执行、结果及真实JSON示例。Zod严格解析，1–3步，禁止额外字段、任意坐标、代码或场景外能力；示例逐一经schema测试。Live不使用玩家关键词触发行动，模型自主决定结构化意图。 |
| 结果与合作经历不足 | 回执保存行动type/status、实际材料/工时、失败码与真实变化。上下文含人格、目标/标签、当前/pending、自己的包、附近感知、工程缺口、最近结果、事实/声称/观点记忆和玩家发言。客观赠送/贡献/同行/合力事件持久化，失败退避防风暴。 |

Debug 展示目标和调整、最近经过校验的完整安全结构化决定（含计划/赠送决定）、当前及pending、policy、库存、双方贡献、规则回执、记忆及共享账本。只在提示中截短长事实引文，不覆盖存档完整事实；最长中文发言和复杂状态通过12,000字节上下文预算回归。不展示私有思考、凭据或原始供应商错误；包括JSON转义后的标记也会检查。

v1/v2 SQLite 先相邻备份再事务升级v3，保留资源、坐标、工程、在途单NPC步骤、回执、记忆。旧档无法追溯的材料/工时标记「旧档记录」，不伪造贡献者。原共享预算账本继续保留，重开/重启不重置；单NPC在途、开关、暂停/断线/重开/代次保护和thinking三态均回归。失去原对话的玩家未决赠送会作废，但从未预扣材料；岑砚已发出的有效赠送可跨重启由玩家明确确认。

## Phase 3.1 真实模型人工步骤

Phase 2 的真实对话和 Phase 3 的真实自主思考采集由用户本人确认。本次 Phase 3.1 只使用 Mock 和本地桩，没有真实供应商输出、计费或延迟数据。以下步骤留给用户明确授权后的独立人工验证。

1. 使用专用新存档和对应预算账本。通过服务端环境设置自己的供应商 HTTPS 地址、模型、专用 Key、请求和费用上限，先保持 `LLM_AUTONOMY_ENABLED=false`。按供应商要求设置 `LLM_ENABLE_THINKING`，分别核验留空时字段省略、非空时按布尔值处理。浏览器对话标记应为 Live。
2. 从空包开始合法采集并和岑砚自由表达协作意图。比较普通问答与有意行动时的规则回执。在岑砚同意时确认 `follow` 能跨关闭对话继续；走停、转弯、到桥及取消均由世界规则反映。必要时记录措辞变化和拒绝样例。
3. 用真实背包提议赠送并观察模型独立接受或拒绝；对岑砚提议分别在界面明确同意和拒绝。等过期或走出范围后重试，记录回执及背包变化。让双方分批交自己的材料、一起施工并实际过桥，用工程栏复核贡献数和重叠工时。
4. 在岑砚移动或等待时提出几种新请求，记录模型实际选择的继续、替换、暂缓或拒绝。检查待执行项跨正常停服重启恢复、提升并重新校验。关掉未完成的对话，观察迟到答复是否仍被忽略。
5. 合作后正常退出服务并重启，再询问共同经历。核对回答所依据的规则事实、累计请求数及账本成本，记录供应商实际账单和已授权范围内的延迟。仅在需要检验后台自主决策且获额外调用授权时开启自主开关。
